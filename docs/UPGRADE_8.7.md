# 8.7：四角色、一鍵必殺與競技介面

這次升級以目前 Canvas／Node 60Hz 引擎為基礎，不引入另一套遊戲引擎。街機劇情、練習、1v1、2v2、觀戰、暱稱、房名與舊冒險模式全部保留；依使用者要求移除 Sam。舊版 Sam 選角回退阿志，瀏覽器存檔遷移保留金幣與戰績。

## 參考來源與取捨

實際閱讀 vincent-li/kof13 的 README、static/app/utils/idcards.js、movement.js、gladiator.js；參考提交 `741224ebcd2e8539f47f8d140208763ecd18c844`。

借鏡的概念：用資料描述各招式與圖集矩形、動作有明確起訖與姿勢、角色朝向一致、將輸入／動作播放與畫面組裝分開。新程式為本專案自行實作，沒有複製參考專案的角色圖、音效或程式片段；不引入其舊 Node／MongoDB／Cocos 相依。既有 PNG 圖集保留，新增的是原創程序化技能特效與播放控制，不宣稱所有角色已重畫整套高解析動畫。

開場 30 能量就能使用專屬技。鍵盤直接 U／O，手機直接按專屬技／超必殺；不必搓招。原有方向指令仍可使用。技能只能在可行動或合法命中取消時發動，不能無視硬直；能量不足有提示。

核心改善包括：取消輸入不再被無法負擔的招式遮住、相同防守輸入不因席位更新順序多擋一幀、2v2 與 1v1 共用飛行道具建立規則、塞子三段命中上限一致。技能事件在實際開始時產生，特效不修改模擬或亂數狀態。低特效限制粒子與特效個數，減少動態模式避免旋轉位移與閃動。

## 介面與相容性

主頁重新整理遊玩模式、選角、血量、能量、技能可用狀態及觸控操作；2v2 與觀戰沿用一致視覺。保留舊入口與邀請連結。技能說明與幀資料可展開閱讀，核心操作優先顯示。角色 KO／勝利動作可停在結尾姿勢。

舊冒險腳本移到 legacy.js，按鈕採明確白名單事件委派，無 eval／內嵌腳本，不放寬全站 CSP。這是讓既有模式在現行安全標頭下可操作的相容修復。

## 安全與開發流程

角色欄位先檢查型別與 own property，修復畸形 join 使程序退出的漏洞；無效換房／觀戰先驗證，不會先取消原比賽。觀戰仍只讀。有真實 WebSocket 的負面案例與瀏覽器實際操作測試。加入 lockfile，CI 使用 npm ci。

本版沒有加入 Ready、大廳列表、重連保席、私密房／邀請授權，這些仍依技術健檢的分批 PR 計畫進行。房號與觀戰連結不構成私密存取控制。伺服器重啟仍會中斷現有房間。

合併前須通過 check、全部 Node 測試、瀏覽器測試與回滾收斂；仍需使用者安排兩／四台實機與正式規格硬體驗收。合併只是程式碼變更，不觸發正式部署。
