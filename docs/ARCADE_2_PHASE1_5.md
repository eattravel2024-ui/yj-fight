## 圖片處理與品質

整張來源畫布等比例 Lanczos 縮放，不作角色重繪或重新生成。Fullbody 置中於 768×1024；肖像 512×512；HUD 256×256，各保留透明外框，沒有拉伸、沒有把灰底／格紋烘焙進圖。輸出 WebP quality 92、alpha 100、exact；高解析 PNG 原檔未變動。

部分原圖衣服／特效在原畫布邊界結束，這次完整保留提供的構圖，只新增透明空間；不宣稱補回原本畫框之外的內容。所有輸出的外側像素均透明，沒有新增邊界裁切。實際 Chromium 合成到深／淺背景檢查，沒有不合理黑色矩形或處理產生的黑邊；原有漫畫黑描邊與發光特效保留。

來源有大量 alpha=254 的近不透明像素，並非整個主體被處理成半透明。沒有內嵌 ICC profile 需要額外色彩轉換。原圖與重新打包輸出的逐位元組 hash 已核對，12 張衍生圖可於目前環境重建出相同 bytes。

## 整合位置與共同引用

- `public/character-art.js` 是單一 UI 圖片對應來源，提供 `fullbodyAsset`、`portraitAsset`、`hudAsset`。以真正角色 ID 查詢，不把圖片欄位加入確定性 `CHAR` 或 rollback state。
- 主選單使用目前已選角色的 Fullbody，並以另一位既有角色作背景搭配；沒有新增選角操作或重排 Phase 2 頁面。兩張按需大圖不是一次載入全部 12 張原 PNG。
- 既有四張角色卡換成 512 肖像，保留原控制 ID、選取與線上協定。移除只對新圖生效的舊照片放大／位移裁切，讓新圖用 contain 完整呈現。
- 1v1／2v2／觀戰的既有血條、房間席位頭像引用對應 HUD 圖；沒有重構 HUD、血量／計時器或戰鬥邏輯。
- 新圖載入失敗先退回同角色舊肖像；若舊圖也失敗，顯示角色名稱與「圖片暫未載入」。重複渲染不會無限重試，頭像文字 fallback 保留緊湊尺寸。

**塞子 UI 與戰鬥外型不同**：提供的新立繪是持毛球武器的人形造型，HUD 另有傾斜人頭／毛球構圖。本次依來源用於 UI，沒有擅自改回或旋轉，也沒有把它當作原毛球戰鬥圖集。
