# 8.9.9 塞子毛球與寫實頭部動畫

依使用者提供的圖一製作白色毛球、金屬接頭與人頭的角色，沒有另加手腳或人形身體。頭部依圖二照片的禿頭、五官、膚色重新生成多角度表情，讓寫實臉部與毛球自然銜接；不是將同一張照片直接貼在所有姿勢上。

| 參考姿勢 | 遊戲動作 |
| --- | --- |
| 待機 | 兩個呼吸／表情姿勢交替 |
| 前進 | 毛球前後滾動；朝左整體翻轉 |
| 蹲下 | 按住下方向維持壓低的毛球姿勢，不再循環掃擊 |
| 拳擊 | 蓄勢、頭槌、連續頭槌與重撞，沿用原攻擊按鍵 |
| 踢擊 | 毛球翻滾撞擊與低掃，沿用踢擊按鍵 |
| 跳躍攻擊 | 跳躍、上衝頭槌與空中翻滾 |
| 必殺 | 蓄力 → 毛球旋風 → 收招；藍色風帶加上「高雄發大財」原有金幣 |
| 勝利 | 抬頭、伸長金屬接頭的得意姿勢 |

另有防禦、近身撞擊、受擊及倒地。21 個透明關鍵姿勢編排成 17 動作 × 10 時序格；170 格包含停留／重複姿勢，尚非 170 張獨立過渡張。攻擊動畫依模擬的前搖、有效與收招階段播放，命中停頓沿用既有機制。

來源與錨點：`assets/sezi/reference-poses.png`、`reference-poses.json`。執行 `python tools/build_azhi_video_atlas.py --fighter sezi` 可重建 `public/sprites/sezi.png`；`make_sprites.py` 也保留此來源。作者工具需要 Pillow，VPS 執行遊戲不需要新增套件。招式展示圖同步更新。

四位角色現均使用 384×300 影格。塞子保留 292px 地面錨點與 0.76 顯示比例，寬幅容納伸頭與翻滾；輪廓改為較矮、較寬的毛球。鏡頭、血條版面、碰撞／受擊框、傷害、技能能量及攻擊幀數保持原規則，未藉美術縮小判定。四位角色、全部遊戲模式、Ready、觀戰及 Rollback 均保留。

## 驗證與合併

語法檢查及 170 項 Node 測試通過，圖集重建結果逐位元組相同。6 項相關瀏覽器測試通過，涵蓋 170 格的透明邊界與左右翻轉、四位角色出場、四人對戰、技能真實傷害、手機觸控，以及四種視窗尺寸的主遊戲／團隊舞台與血條同屏。這些是本機瀏覽器驗證，尚未進行跨實體裝置驗收。

建議合併此美術更新，沿用目前開發分支與 [手動更新流程](MANUAL_RELEASE.md)。部署後強制重新整理以載入 8.9.9 素材；如需回滾，使用更新腳本保存的完整備份。未連線或部署正式 VPS。
