# 8.9.8 維尼圖片參考動畫

依使用者提供的八格姿勢圖生成 21 個透明關鍵姿勢，維持紅色短帽衫、黃色圓身與人物臉部特徵。這次不把灰底、分格、文字或光效整張貼入遊戲。

| 參考姿勢 | 遊戲動作 |
| --- | --- |
| 待機 1／2 | 站姿與掩嘴微笑循環 |
| 前進 | 左右步交替；朝左時整體翻轉 |
| 防禦 | 雙臂護頭，沿用真實格擋特效 |
| 拳擊 | 蓄勢、輕拳、連拳與重拳 |
| 踢擊 | 抬膝、高踢與低掃 |
| 必殺蓄力 | 雙手蓄力 → 舉手推掌 → 收招，配合「不同意的請舉手」及掌波 |
| 勝利 | 舉拳勝利姿勢 |

補製跳躍、衝刺、升龍、抓取、受擊及倒地，映射到既有 17 動作 × 10 時序格。170 格包含停留／重複姿勢，並非 170 張獨立手繪中間張。

素材與編排記錄在 `assets/winnie/reference-poses.png`、`reference-poses.json`。用 `python tools/build_azhi_video_atlas.py --fighter winnie` 重建；`make_sprites.py` 也會沿用此來源，避免改回舊美術。兩個作者工具需要 Pillow，VPS 執行遊戲不需要 Python 或新套件。招式展示圖同步更新。

維尼由 240×300 改成 384×300 以容納完整拳腳，渲染器依角色讀取尺寸；300px 高度、292px 腳底錨點、0.76 顯示比例、固定鏡頭保持一致。其他角色來源、技能名稱、攻擊幀數、傷害、判定框、Ready、Rollback、全部模式及即時接技／傷害提示不變。

## 驗證與合併

語法及 169 項 Node 全套測試通過，圖集重建可重現。6 項相關瀏覽器測試均通過，涵蓋 170 格透明度／邊界／左右翻轉、四位角色技能與四人對戰；另檢查大招真實傷害、手機觸控與血條／完整舞台同屏。

建議合併這次獨立的維尼美術更新，沿用目前開發分支及 [手動更新流程](MANUAL_RELEASE.md)。所有玩家強制重新整理以載入新圖集；需要回滾時使用更新腳本保留的完整備份。未操作正式 VPS。
