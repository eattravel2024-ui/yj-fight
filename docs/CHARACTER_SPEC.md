## 緩衝、取消與手感

一般 Input Buffer 10F，阿志 12F；命中停頓時保留輸入，過期才刪除。普通取消須真實命中或被擋，且在每招的 cancelWindow 內；假動作是明確允許落空取消的例外。J → J → J 保留，突進可接踢／升龍／U／終結，重拳可接 U／O／所屬追加必殺；新增招式不允許取消回輕拳形成循環，終結技與投技不能取消。每招 Hitstop／Hitstun／Blockstun 使用資料表，1v1／2v2 共用 applyContact，未新增與繪圖 FPS 相依的時間判定。

## 共用 Throw／Throw Tech

- H 使用各角色 Startup 與短 active range；必須雙方在地面、面向對方、距離內、目標存活且非隊友。不能抓取受擊／防禦硬直、另一組抓取、保護期或升龍起手／有效期中的目標；抓技可突破站／蹲防及精準防禦。
- 被抓後 10 個模擬幀內按 H 解摔，另容許 3F 事前輸入；按住 H 不會持續產生新邊緣。同時投技以解摔處理。解摔零傷害、分離雙方，12F 硬直與 20F 防連抓；保護不在受擊／抓取期間白白耗完。
- 成功時使用明確配對座標與抓取階段，只有 impactFrame 呼叫共用傷害一次。阿志向前快摔，金沙賭神完成實際換位摔；第三人／彈道命中可打斷抓取，死亡、回合結束、重設均清除雙向綁定。
- 成功投完後投手另有 8F 收招硬直，受方至少 26F 硬直與 12F 清醒後保護；抓空依資料表 recovery 承擔風險。不能利用重送封包、連續 H 或回滾重播反覆扣同一次摔投傷害。

## 動畫與素材限制

四角色既有 atlas 均為 17 列×10 格、384×300 cell，腳底素材基準 292、世界地面 448、繪製 scale .76。維尼／塞子 Sprite 保留原 bytes。金沙賭神／阿志重新排列 Idle、步行、攻擊、技能、受傷、勝利與投技關鍵姿勢；追加招式由 actionFor 在實際招式幀切換既有列，抓取與受方姿勢使用實際 grappleFrame。Hitstop 保持顯示幀，動畫不回寫判定。

兩段新 MP4 各約 10 秒、1280×720／24fps，含背景、HUD、文字、特效與鏡頭，沒有 Alpha。已逐段整理站立、步行、跳躍、出招、防禦、受傷、KO 與勝利參考；沒有將不可靠去背的畫格冒充透明 Sprite。以現有 21 個透明關鍵姿勢重排與演出作可行升級；尚缺乾淨透明逐幀、真正中間張及專門抓取／被摔角度。來源、雜湊、時間段與缺少資源集中於 `assets/source-video/phase4_5/manifest.json`，重現 map 位於同目錄 `motion-map.json`。不擅自替換人物頭像、角色 ID 或原技能。
