# 8.9.5 滿版遊戲與遊戲內選單

遊戲不再需要上下捲動網頁尋找選角、房間或設定。擂台使用瀏覽器可用空間，頂列固定保留「大廳／選角／房間／設定」，原本的青藍／桃紅 HUD、四位角色與所有模式繼續保留。

## 操作流程

- 大廳選擇街機、練習、好友 1v1 或團隊／觀戰。1v1 與 2v2 使用一致的遊戲內選單；切換 2v2／觀戰仍沿用原本的同站頁面與協定。
- 選角採大圖卡、已選擇標記與技能名稱。確認鍵固定在面板底部，無須捲到故事說明底端。單人對戰中可預選另一位角色，按「以此角色重新開始」才重開；返回擂台則繼續原角色。
- 房間面板保留暱稱、房名、建立／加入、邀請、觀戰連結、離房、Ready、房主開賽及再戰。線上選角仍受伺服器狀態限制；觀眾不能選角或送出戰鬥輸入。
- 設定面板整合原有音效、特效品質、判定框，以及主遊戲的色彩／本機紀錄設定。另有可選的瀏覽器全螢幕按鈕，瀏覽器不支援時仍維持滿版布局。
- 「操作與招式」保留按鍵說明、幀表、專屬技說明、美術展示及經典冒險入口。
- Escape 關閉選單並回到擂台；再次按 Escape 開大廳。面板支援 Tab 焦點循環及頁籤方向鍵。

## 對戰與動畫

`game-shell.js` 搬移原有控制項，保留 ID 及事件處理，沒有加入另一套假對戰。`game-shell.css` 負責滿版布局、面板淡入、角色選取動畫及桌機／手機橫直向適配。動態效果配合系統的減少動態偏好。

血條、技能提示與觸控列保留自己的空間，canvas 以 contain 顯示完整 960×540 擂台；長寬比不同時留邊，不裁切戰場。角色維持 0.76 比例與固定鏡頭。四位既有動作圖集及技能判定不變。

開選單會清除按住的移動與攻擊脈衝，打字不會誤出招。單人模式暫停邏輯步進；線上模式繼續接收、回滾及送出中立輸入，不能以個人選單暫停多人比賽。伺服器開始比賽時自動收起選單；比賽結束、對手離開或連線中斷時回到房間。實際斷線會清除過期 Ready／房主／再戰狀態，保留房號輸入供手動重加入。

## 驗證與合併建議

`npm run check`、153 項 Node 測試及 14 項瀏覽器測試全部通過，無失敗或略過。瀏覽器案例涵蓋選單焦點／Escape、單人暫停與角色預覽、線上持續同步與中立輸入、主遊戲／團隊斷線重加入、實際 1v1／2v2／觀戰、四位技能、手機觸控、經典模式與既有美術／HUD。

視窗矩陣為 1440×900、1366×768、390×844、844×390，檢查主遊戲與團隊血條、完整擂台、固定選角確認鍵及頁面無捲動。這些是開發環境的真實瀏覽器與本機 WebSocket 驗證；跨裝置公網延遲與實機觸控手感仍需手動驗收。

建議測試通過後，將本次滿版介面作為一個里程碑合併。同一開發分支持續迭代；不新增分支堆疊。部署沿用 [手動發佈流程](MANUAL_RELEASE.md)，不需要新系統服務或 Nginx 設定。更新會中斷現有對局，所有玩家需重新載入；回滾使用既有完整備份及 `deploy/rollback-ubuntu.sh`。

本次未連線或部署正式 VPS。自動斷線恢復、保留比賽進度、私密房／邀請權限仍屬後續工作；房號與邀請連結尚不是存取控制。
