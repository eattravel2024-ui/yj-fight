## STAGE 04 架構

- 正式 ID `legislature`、顯示名稱「立法院」、序號 04；原 `night`／`garage`／`harbor` ID 與天安門建築／坦克不變。原來尚未實裝的 `fur_lab` 保留規劃，序號順延 05。
- `stage-assets.js` 是必要素材狀態，只有匯入工具驗證並完成所有輸出後才會設為 ready。缺檔時選圖顯示「素材待匯入」、禁止建立 encounter、不請求不存在的圖片，也不加入伺服器隨機場景池。
- 工具保留原始 PNG，輸出等比全圖 WebP、640×360 內預覽、背景降噪 WebP、尺寸／格式／SHA-256 manifest。最低 960×540、接近 16:9；拒絕不合規比例、非 PNG、過度透明及覆寫不同原圖。轉檔只需開發機的 Pillow，VPS 執行遊戲不需要 Python。
- 降噪沿用既有離線流程：飽和度 0.77、亮度 0.85、對比 0.91、微量冷色；只改衍生背景，不改角色或 HUD。
- 沿用單層完整背景、960×540 世界、地面 Y=448、本機出生點 274／686、完整擂台固定攝影機；2v2 原四席出生點不變。沒有宣稱真正多層視差。
- 素材啟用後自動接入練習選圖、第五關 `azhi-finale`、VS、戰鬥背景、1v1／2v2 伺服器隨機場景與觀戰。未就緒時末關仍用原廣場，進度、mission ID 與五關數量不變。
- 尚無立法院專屬曲目，準備暫用既有原創 `stage_fur_lab`，不是新製配樂；末關仍沿用專用 `final_boss`。選單／VS／ROUND／KO／勝敗與音量管理不重做。

## 實際戰鬥改變

所有時間以固定 60 Hz 模擬幀計算，與 Canvas FPS 分開；保持命中／格擋後才能取消、不能空揮亂取消。原角色、招式名稱、U=25 能量、O=60 能量及原逐幀 atlas 均保留。

| 角色 | 定位與實裝 |
| --- | --- |
| 阿志 | 速度 3.8 px/F；三連拳減少收招／推退，必殺收招降為 24F。幸運牌作接近掩護，普通／大招投射物基礎值改為 12／25，仍保留種子彩金與普通小額牌。 |
| 塞子 | 速度 3.1 px/F；一般防禦硬直 ×0.85。新按防禦後 4F 精準防禦，零削血、再縮短防禦硬直；24F 冷卻防止連按刷新。獲得 48F 窗口，K／I／U／O 的下一次出招傷害 +20%；被打中失去窗口，落空也消耗，不是無敵或自動反擊。 |
| 金沙賭神 | 抓對手收招時 +22% 傷害。必殺 15F 前搖／29 基礎傷害／42F 收招；大招 21F／42／52F。輕拳吸收只在必殺前 8F／大招前 12F，取代原大招長達 180F 的保護；重擊與摔技仍能破解。 |
| 維尼 | 速度降為 2.45 px/F、威力 ×1.14；重拳 14F／20 基礎傷害、30F 收招，投技 20；地面波普通／大招基礎 18／33。高傷害伴隨較慢移動與可懲罰收招。 |

- 輸入緩衝 8→10F（約 167ms）；命中停頓凍結模擬時仍接受按鍵邊緣。受擊／防禦末段明示可預輸入；按住攻擊不會變成無限連發。受投射物擊中同樣清除舊緩衝，修正原 1v1 與 2v2 不一致。
- 每招擁有獨立 `hitstun`／`blockstun`／`hitstop`／`blockstop`。輕拳防禦硬直 11F、重拳 18F（維尼 21F）、大招 23F；輕拳停頓 6F、重拳 10F、最高 14F。投射物超必殺也使用對應停頓，不再一律只有 7F。
- 核心 `applyContact` 共用近戰／投射物與 1v1／2v2 的傷害、削血、硬直、能量與回饋；保留同幀交易、三段上限、連段遞減、牆邊推退、投技破防及權威勝負。
- 投射物記錄出招 serial，舊投射物命中不再替下一次同名招式開啟取消窗口。新狀態由既有 Rollback 快照保存／重播，不更寫 Rollback 協議或演算法。
- JUST GUARD／RIPOSTE／PUNISH 使用既有命中事件、提示與音訊匯流排；線上仍由確認事件觸發。精準防禦有獨立清脆音色、青色圓弧；反擊／破綻提示顯示真實扣血及硬直。新特效控制亮度，減少動態模式減少粒子。
- 沿用同一 HUD／能量條／技能狀態。選角顯示四種定位與實際速度；招式表區分投射物／多段的基礎傷害並列出硬直，未把效果文案冒充傷害實裝。
