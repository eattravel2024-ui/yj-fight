# 8.9.7 即時接技提示與大招命中回饋

## 玩家看到的變化

擂台下方保留一列即時提示，不增加頁面高度：平時顯示 `J → K → U`，出招時顯示目前招式及可接按鍵。提示使用引擎的 `canChain`、`skillStatus`、命中／防禦確認及實際能量；取消窗口開啟才標示「現在可接」。空揮不會錯誤提示可取消，能量不足則顯示差額。

- `U`：25 能量，一鍵角色必殺，不需要先完成整套連段。
- `O`：60 能量，一鍵超必殺。`K → O`、`U → O` 都需要確認命中／被擋並進入接技窗口。
- 方向指令仍保留：相對角色朝向的 `↓ ↘ → + J` 為必殺，`→ ↓ ↘ + K` 為升龍。

每次技能會顯示名稱與作用，命中後顯示「實際扣除 HP、段數、累計傷害」，並區分防禦減傷、彩金及反擊加成。空揮會顯示距離／高度提示；金沙賭神的霸體也會顯示剩餘秒數及一次輕拳吸收。舊的輸入小標在即時接技提示啟用時收起，避免互相遮擋。

單人回饋來自真實模擬事件；1v1／2v2 線上傷害回饋只接收伺服器確認事件，依事件 ID 去重，不把預測或回滾重播累加成額外傷害。觀戰保持只讀，可看到技能及傷害，不顯示玩家接技操作提示。清空房間／重開／再戰會清掉舊回饋。

## 大招實測與修正

原版已經有大招傷害，但沒有清楚的傷害回饋；近身招在遠處會落空，850ms 全景立繪又遮住實際命中。改為 320ms 小幅立繪提示，保留人物與技能動畫、固定鏡頭，讓打擊過程可見。

下表為地面近距離、未防禦、無先前連段及額外加成的測試結果；1v1 與 2v2 相同。實際仍受距離、防禦、反擊、彩金、連段衰減及剩餘血量影響。

| 角色 | O 超必殺 | 實測傷害 | 實際作用 |
| --- | --- | --- | --- |
| 維尼 | 全票通過掌 | 28 HP | 大型遠程下段掌波，蹲防可擋 |
| 塞子 | 港都金流大爆發 | 三段合計 36 HP | 旋風向前突進，距離不足可能只中部分段數 |
| 金沙賭神 | 梭哈人生不回頭 | 32 HP | 近身重擊；3 秒內吸收一次輕拳並強化反擊，重拳／摔技可破解 |
| 阿志 | 油箱滿到天靈蓋 | 一般 30 HP | 強化遠程牌，保留彩金加成，大招不再抽到小額牌 |

阿志原本的 O 沿用 U 抽牌，因此可能花 60 能量卻抽到小額牌；現在 O 保底正常傷害，U 仍保留原本抽牌特色及決定性亂數流程。

同時修正連防多段攻擊的漏防：原本防禦硬直也會關閉防禦，使塞子的第二段穿過仍按住的防禦。新增獨立 `blockstun` 計時，按住正確防禦可繼續擋；放開防禦、用錯站／蹲姿勢或真正受擊硬直仍會中招。1v1、2v2 及延遲輸入回滾均涵蓋測試。

傷害事件新增 `target`、`appliedDamage` 與近身反擊加成標記；擊倒時只報告對手真正失去的血量，不把溢出傷害當成實際扣血。

## 驗證、合併與部署

`npm run check`、169 項 Node 測試及 17 項瀏覽器測試全部通過，無失敗或略過。Node 驗證四位大招扣血、段數、能量、範圍、防禦、小額牌保底、霸體反擊、擊倒溢出傷害與回滾一致性；真實瀏覽器操作 J／K／U，驗證四位 O 的血條與傷害回饋、近身落空原因及線上確認回饋，並保留全部模式與橫直向布局回歸。

建議將此接技／大招回饋作為下一個合併里程碑，沿用既有分支。戰鬥規則已有修正，手動更新後所有玩家務必重新載入，避免新舊模擬混用。沿用 [手動更新與完整備份回滾](MANUAL_RELEASE.md)，不需更改 Nginx 或新增系統套件。未連線或部署正式 VPS。
