## 完成的畫面

桌面三區分工：左側玩家大立繪、名稱、稱號、真實出場台詞與三項能力；中央四角色肖像卡及實裝必殺／超必殺；右側實際 CPU 或線上對手的大立繪、狀態與房間名單。漫畫斜切底板、半色調、黃紅選框、單次立繪淡入位移、320ms 能力條與確認亮框共用現有街機語言。沒有新增來源不明的美術。

每個角色由既有 ID 查詢：winnie／sezi／gambler／azhi。名稱、稱號、台詞、技能描述、能力數值直接讀 `AzhiCore.CHAR`／`moveFor`；圖片來自 `character-art.js`。威力、移動速度及跳躍係數是實際引擎係數，條形長度按四角色相同欄位最大值比較。不顯示不存在的 99% 暴擊、假防禦值或未實裝技能。

第一次實際檢查發現桌面技能說明超出可視高度、手機被舊卡片橫排樣式影響，已修正卡片高度／排版與頁首密度，再於 1920×1080、1366×768、390×844、844×390 驗證。桌面技能與確認可同時看到；手機固定底部確認，內容可在對話框內垂直捲動，沒有水平溢位。右側 CPU 不任意提供尚不存在的難度／角色設定：街機依關卡、練習是維尼木樁。

## 選擇與確認

- 點擊或方向鍵／WASD 只改 UI 草稿，大立繪、技能、能力條隨之更新；不寫入存檔，不傳選角封包，不改進行中的角色。
- Esc／返回／切換面板會取消未確認草稿。重新進入顯示已確認角色。
- Enter／Space 或底部主按鈕確認。本機透過正式 client adapter 套用並保存，再呼叫原本開始／重新開始控制；保留街機進度、五關循環與練習流程。
- 團隊角色保存於獨立 `azhi_team_character_v1`；線上以 roster 確認後保存，本機／URL 帶入角色明確確認後保存。不覆寫街機進度與經濟資料；瀏覽器禁止 localStorage 時保留本次工作階段選取。
- 線上只有明確確認才使用原有 `select_character`；等待伺服器 roster 的實際角色一致後回房間。相同角色不重送換角，避免無謂重設 Ready。四秒未收到確認會解鎖重試，不冒充成功，也不自動 Ready／開賽。
- 觀戰者與比賽中選手不能換角；右側顯示真實玩家暱稱／角色／Ready。已有房間時原跨模式保護保留。
- 確認期間禁止連點；離開或取消使待執行轉場失效，不會稍後偷偷開始本機比賽。減少動態效果時不播立繪／能力條動畫。
