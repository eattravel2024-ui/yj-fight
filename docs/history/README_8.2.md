# 阿志向錢衝 8.2 · 60Hz 連段手感與美術整合

本包是可直接更新 `/opt/azhi71` 的完整遊戲專案，包含 Sam、維尼、塞子、金沙賭神、阿志五人。保持 Node.js 內網 `127.0.0.1:31071`、Nginx 外網 `18071`、systemd `azhi71.service` 不變，**只替換該遊戲服務**。

## 8.2 真正新增／修正

- 60Hz 固定步進保持；輸入佇列縮至 **8 邏輯幀（約 133ms）**；收招前八幀預先輸入可自動出招。
- 具備 Hit / Block 確認條件的分級 Cancel Tree；支持三段輕拳、輕接重、重接必殺、**必殺命中後接 O 超必殺**（超必殺消耗 60 能量）。
- 輕拳、重拳與必殺分別施加 5、8、10 幀命中停頓；超必殺 12 幀；防禦則 4 幀。
- 牆角擊退若被邊界截斷，剩餘力道反推攻擊方；角色推擠箱防止重疊。
- 線上雙人保留 60Hz 伺服器權威判定、30Hz 快照，加上 **雙方確認再戰**、房間重用與前端最多 2.5 幀、只影響畫面的短距離預測。**未實作完整 Rollback。**
- 金沙賭神新增伺服器決定的種子式飛牌手氣（JACKPOT／普通／爛牌），阿志超必殺附帶三秒黑金一次性輕擊霸體。
- 手機補齊 `I 升龍`、`O 超必殺`；Mac 實體 `KeyO` 對應超必殺。
- 保留 8.1 原有的五位角色 17×10 動作 Sprite Sheet、五位肖像與場景，新增高解析角色招式美術展示、原創透明 PNG 命中特效圖集、五張超必殺人物特寫、殘影、起跳拉伸與落地壓縮效果。

參考 `vincent-li/kof13` 專案的角色動作資料分層與動畫圖集組織概念，**沒有直接包含 KOF XIII 的原版圖片／音效**。新增素材使用本對話先前為五人製作的原創 AI 美術作整理；原圖表非結構化且含說明文字，因此加入展示欄，並將實際戰鬥所需特效獨立產生透明動畫圖集。角色動畫繼續使用經驗證的原創 8.1 Sprite Sheet。素材檔案可再編輯與替換，但人物肖像／公眾人物衍生形象使用前請自行確認授權。

## 一、先在 Mac 上傳更新包

```bash
scp ~/Downloads/*8.2*.zip root@YOUR_VPS_IP:/tmp/azhi82.zip
```

如果 SSH 22 Port 拒絕連線，請先由 VPS 網頁主控台修復 SSH 或以其他有權限的方式上傳；不要停用防火牆或現有網站。

## 二、在 VPS 解壓縮、先檢查

```bash
unzip -tq /tmp/azhi82.zip
mkdir -p /tmp/azhi82-update
unzip -q /tmp/azhi82.zip -d /tmp/azhi82-update
bash /tmp/azhi82-update/azhi71/deploy/upgrade-ubuntu.sh --check
```

## 三、確認 --check 通過後更新

```bash
bash /tmp/azhi82-update/azhi71/deploy/upgrade-ubuntu.sh
systemctl status azhi71 --no-pager
curl -fsS http://127.0.0.1:31071/healthz
```

健康檢查預期版本 `8.2.0`。Nginx 仍提供 `http://YOUR_VPS_IP:18071/`。瀏覽器可能需要 Cmd+Shift+R 強制重載。

更新會短暫停止 `azhi71`，正在對戰的人會被斷線；腳本建立 `/opt/azhi71.backup.時間戳` 備份，啟動或健康檢查失敗則嘗試自動回滾。**不變更 SSH、UFW、Nginx、Docker、6.9/7.0。**

## 四、操作與試玩

- 電腦 A/D 移動、W 跳、J 輕、K 重、Q 踢、E 掃、H 摔、I 升龍、U 必殺（40 能量）、**O 超必殺（60 能量）**、L 防、Shift 衝。
- 練習建議：J → J → K → U → O（必須正確命中且有足夠能量；新連段不保證任何距離都能成功）。
- 對戰後，雙方在原房間按「再戰一場」，兩人都同意後自動重新開始。
