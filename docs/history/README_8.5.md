# 阿志向錢衝 8.5 — 四人 2v2 與即時觀戰

## 這次新增了什麼

- **2v2 四人同場**：不是兩個獨立 1v1，也不是輪流換人的 Tag Team。紅隊兩名、藍隊兩名，四位玩家同時在一個 960×540 舞台戰鬥，各自操控一名角色。
- **紅藍隊伍**：加入順序 1、3 是紅隊；2、4 是藍隊。每名角色有自己的 HP 和氣量；沒有隊友傷害，整隊兩名成員都倒下才輸掉該回合；每場三戰兩勝。90 秒到時比較兩隊剩餘 HP 總量。
- **五位既有角色全數保留**：Sam、維尼、塞子、金沙賭神、阿志；可與隊友選同一角色。用同一批 8.4 原創 Sprite Sheet、美術、技能參數。
- **四組 Rollback 輸入**：新增 `public/team-core.js`（60Hz 2v2 物理）並把 `public/rollback.js` 改成依 game.players.length 支援 2 或 4 組網路輸入，保留 8.4 的 1v1 模式。
- **觀戰席**：同房最多 24 人可觀戰，**不佔**四個玩家席。可以中途加入，看即時血量、角色動作、比分、投射物和命中效果；只有權威只讀畫面，不允許攻擊、投票或更改角色。
- **兩種觀戰**：四人戰或原本 1v1 房間均可從 `/team.html` 輸入房號觀看。原本 1v1 頁面加入「複製觀戰連結」按鈕。
- **同房再戰**：四位玩家都投票後原房重開；觀眾會自動看下一場。玩家離線會中止當局，但觀眾離線**不會**中止比賽。

## 操作

1. 用瀏覽器開啟 `http://YOUR_VPS_IP:18071/team.html`（或從原版首頁第 4 個選項進入）。
2. 玩家 A 選角色，留空房號按「建立／加入」，得到 8 碼房號。
3. 玩家 B、C、D 各自用自己的瀏覽器和裝置輸入同房號；順序分配紅 A1、藍 B1、紅 A2、藍 B2。第 4 人加入後自動開始。
4. 額外的觀眾開啟「觀戰模式」，輸入房號；也可分享「複製觀戰連結」，直接加入。房間中途進入會收到最新的狀態。
5. 兩隊打三戰兩勝，結束後四位玩家點「再戰」即可重賽，觀眾留在房間繼續看。

**操作鍵**：A/D 移動、W/S 跳/蹲、J/K 輕重拳、Q/E 踢/掃、H 摔、I 升龍、U 必殺、O 超必殺、L 防禦、Shift 衝刺。手機有觸控按鈕，建議橫向遊玩。

## 同步架構

- 四個玩家各有獨立的、包含短按脈衝的逐幀輸入。伺服器用 60Hz 確定性引擎 `TeamCore` 作權威判定；玩家端也是 60Hz，同一套 Rollback Session 保存 30 幀完整歷史，晚到輸入逐幀回滾重新計算。
- 玩家端約 30Hz 收到確認輸入、事件與權威檢查點；觀戰者約 15Hz 收到**只讀**狀態快照＋事件，沒有逐幀輸入重播和權威操作能力，減少頻寬成本。
- 同一房間的玩家共用時間、回合、勝負與亂數種子，玩家加入順序決定座位號。

## 升級 VPS

這是**覆蓋現有 `azhi71` 應用**，但並非強制改 Nginx/SSH/Docker；舊版會完整備份。

Mac：
```bash
scp ~/Downloads/*8.5*.zip root@YOUR_VPS_IP:/tmp/azhi85.zip
ssh root@YOUR_VPS_IP
```

Ubuntu VPS：
```bash
unzip -tq /tmp/azhi85.zip
mkdir -p /tmp/azhi85-deploy
unzip -q /tmp/azhi85.zip -d /tmp/azhi85-deploy
bash /tmp/azhi85-deploy/azhi71/deploy/upgrade-ubuntu.sh --check
# 確認測試通過、且這台 VPS 可短暫中斷 azhi71 後：
bash /tmp/azhi85-deploy/azhi71/deploy/upgrade-ubuntu.sh
```

驗證：
```bash
curl -fsS http://127.0.0.1:31071/healthz
systemctl status azhi71 --no-pager
journalctl -u azhi71 -n 40 --no-pager
curl -I http://127.0.0.1:18071/team.html
```

預期 healthz 版本 `8.5.0`。若不符合，先查看日誌；可以使用已打包的 `deploy/rollback-ubuntu.sh` 手動還原最近一次備份（**會提示輸入 YES**）。

## 重要限制

- **新模式是公測版**：目前已完成自動化及本地瀏覽器測試，但未用四台真實設備跨網際網路做延遲壓測。不能宣稱商業級 Rollback 品質。
- 觀戰畫面採 15Hz 快照＋位置插值，不是觀眾端 60Hz Rollback，因此特效、動畫的完整度可能略低於參戰玩家。
- 房間只憑房號加入，尚無帳號驗證／私密觀戰密碼／邀請白名單。**知道房號就可以觀戰**，避免分享敏感資訊。
- 若以純 HTTP IP 位址上線，WebSocket 是未加密的 `ws://`；正式公開建議使用**網域 + HTTPS/WSS**，尤其是玩家身份和排行未來增加時。
- 四人遊戲更吃 CPU 和網路，`/healthz` 可以看到房間數、連線數與觀眾數。每個房間最多 24 位觀眾；房數與玩家連線上限由伺服器限制。
- 若任一玩家中途斷線，當前四人戰鬥會取消；目前未做到玩家斷線回原座與保留完整局面。觀戰者則可以重新開同一觀戰連結。
- 還未提供多人語音、聊天、隊友角色交換、排位賽或賭注。
