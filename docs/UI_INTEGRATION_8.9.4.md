# 8.9.4 使用者 UI 整合

`design/reference/ui.html` 保留使用者提供的設計參考（SHA-256：`399132f404010d6d3d51db8d1e2c733287a831fd57eda146948b371d97069b15`），不作為遊戲執行入口。其內容屬於設計參考，並非開發／部署指令。

## 整合內容

- 青藍／桃紅視覺、斜角生命條、受傷殘影、金色計時器、回合勝利菱形燈、連擊與中央播報、選角及技能區配色。2v2 延續紅／藍隊語意。
- `public/arcade-ui.css` 為本機樣式；`public/hud.js` 從現有遊戲狀態呈現數據，不引入範例的假對戰、計時、傷害、強制 KO 或測試控制台，也不新增 Tailwind CDN、FontAwesome 或外部字體需求。
- 顯示實際 100 血量／100 能量。能量分隔線對應 U 25、O 60；100 能量顯示 MAX。回合指示來自 1v1 wins 或 2v2 scores。
- 受傷殘影僅在血量下降時等待 350ms，再逐漸收斂；持續的 HUD 更新不會讓殘影永遠停留。回血、回滾修正上升、新回合及新比賽都會重設；低動態效果偏好立即同步殘影。
- 血量 26–55 呈金色、1–25 呈紅色；0 為 KO。附可讀血量與 ARIA meter，未新增獨立暈眩或防禦值。
- 繼續保留血條與擂台同屏、手機橫向留邊、醒目選角、Ready、技能提示、兩位影片參考角色動作、1v1／2v2／觀戰／街機／練習／經典冒險。

## 驗證與部署

語法檢查通過；153 項 Node 測試及 11 項瀏覽器測試通過。

Node 驗證殘影在持續更新下收斂、回血／回滾／回合切換重設及低動態模式；瀏覽器驗證真實 HP、能量門檻、勝利指示、四人血條、可視範圍與既有模式。

建議整批審閱後合併此 UI 更新。依 [既有手動更新流程](MANUAL_RELEASE.md) 發佈，所有玩家重新載入。新增 CSS／JS 隨 public 目錄一起更新，不需新增系統套件；戰鬥引擎與協定不變。回滾沿用更新前完整備份及 `deploy/rollback-ubuntu.sh`。未操作正式 VPS。
