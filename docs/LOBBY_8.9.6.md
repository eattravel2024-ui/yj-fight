# 8.9.6 大廳層級與選角整理

大廳依「選玩法 → 選角色 → 開始」呈現，保留迷因角色與青藍／桃紅街機風格，減少同時搶眼的區塊。

- 主視覺改成小型「選擇戰鬥模式」，移除額外的裝飾角色展示，直接使用可操作的四位角色卡。
- 桌面左側選模式、右側選角色；模式只標示目前選項，選擇後不跳去另一張選角面板。手機使用兩欄模式與精簡角色卡，橫向仍採左右布局。
- 照片透過 CSS 裁切原圖內的照片區域，去掉既有不同色斜紋、框線及圖片內重複姓名。外層名稱、技能、選取框與勾選標記統一；不重製或修改原圖檔。
- 底部固定顯示模式與「角色 · 專屬技」，並以明亮青藍色主按鈕開始戰鬥。選角面板的原始狀態文字保留供無障礙播報，畫面不再重複顯示整行「目前選擇」。
- Fight Fund 區塊及 `coinsHeader` 已從 HTML 和更新邏輯移除。既有存檔、闖關獎勵與配色購買不變，不會清除玩家進度。
- 1v1／2v2 仍先進房間並由 Ready／房主開賽。觀戰維持只讀；切換同站模式時會攜帶選角，角色網址參數只接受四位既有角色。

所有遊戲模式、技能／動畫、戰鬥判定、Rollback、命名、邀請與設定繼續保留。選單動畫與減少動態效果也沿用現有設定。

## 驗證與發佈

語法檢查、153 項 Node 測試與 15 項瀏覽器測試通過；角色網址參數補強後另重跑相關流程並通過。另檢視 1366×768、390×844、844×390、320×640 主遊戲／團隊大廳截圖。瀏覽器新增同頁選模式／選角、固定主按鈕、740 幣舊存檔沒有 Fight Fund、跨模式保留角色、觀戰與不合法角色參數的案例。

建議將這次介面整理獨立作為下一個合併里程碑，沿用 `feat/signature-entrances` 迭代。部署沿用 [手動更新流程](MANUAL_RELEASE.md)，不需更改 VPS 系統服務、Nginx 或防火牆。更新後所有玩家重新載入；回滾使用既有完整備份與 `deploy/rollback-ubuntu.sh`。未操作正式 VPS。
