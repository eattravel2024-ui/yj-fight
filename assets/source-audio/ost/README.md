# BIG TALK / REAL FIGHT — 原創街機格鬥 OST 音樂包

**21 段原創可播放音訊**：12 首 BGM 循環曲、9 段 VS／KO／勝敗／角色登場短曲。

- `audio/`：OGG 雙聲道遊戲用音檔。
- `midi/`：可重新編曲／換音色的 MIDI 音符工程。
- `manifest.json`：供 Codex 讀取的曲目與場景／事件對應。
- `tracklist.csv`：曲目規格。
- `AI-Music-Prompts.md`：需要更精緻真實樂器或 AI 商業配樂時可用的提示詞。

## 音樂定位及品質

這是從零編曲、以原創波形與噪音合成的 **復古電子街機風格配樂（MVP／試聽與遊戲原型可用）**；不是音樂生成平台製作的真人樂隊、管弦或廟會實錄，也沒有使用外部取樣或任何 SoundFont。若希望達到商業 2D 格鬥遊戲的高質感音色、混音和精確無縫循環，仍建議交由音樂工具或 DAW 重新配器、母帶處理並逐首驗聽。

## Codex 使用

1. 將 `audio/` 和 `manifest.json` 放到 VPS 的素材收件夾。
2. 依現有程式的場景與狀態 ID 對應音樂；勿假設尚未實作的介面已存在。
3. `loop: true` 才循環播放；`loop: false` 是一次性短曲。
4. 建立 BGM/SFX 獨立音量、音訊解鎖、去重播放、300ms 淡入淡出，以及必要的音訊預載。
5. 開發時先使用這套試聽版；後續可以換同檔名的重新編曲音檔，無須修改事件對應。
6. 檢查循環點與手機播放效果，避免每次重新 render 都觸發播放。
